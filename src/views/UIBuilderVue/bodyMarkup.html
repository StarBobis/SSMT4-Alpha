物理效果

物理与自动动画控制

物理模式说明
- 弹性 (K) 越大，回弹越快，动作越紧致。
- 阻尼 (D) 越大，晃动越少，接近 1 时更稳定。
- 自动动画 组件空闲时也可按设定持续运动。
- 乳摇模式 会保留更多惯性尾部和拖拽延迟。
- 重力 用于制造额外下坠感。
自动动画 / 轨迹说明
- 自动动画 开启后会生成对应的 $auto_x 等控制变量。
- 轨迹刷新 用于控制混沌轨迹多久重算一次。
- 幅度 / 幅度范围 用于控制自动运动范围。
- 随机 / 轨迹种子 用于改变轨迹初始状态。
- 动画速度 控制函数或轨迹在 0 到 1 内的推进速度。
- 响应 / 回弹 / 重力 用于调整整体动态手感。
算法说明:
- 弹性 (K) 影响回弹速度，值越大越灵敏。
- 阻尼 (D) 控制速度衰减，越接近 1 越稳定。
- 自动强度 为 1 时完全跟随自动轨迹，0 时关闭。
- 自动范围 控制自动运动时的最大偏移。
- 随机 / 轨迹种子 影响轨迹的相位和形态。
- 幅度 / 幅度范围 影响函数模式或混沌模式的振幅。
- 轨迹刷新 控制混沌模式的采样频率。
- 乳摇模式 会产生更多拖尾和延迟。
- 重力 用于增加向下偏移。
- 适合摇杆、跟随滑条、双态控件等需要动态反馈的组件。
乳摇模式会保留更多边缘延迟、回弹和下坠感，适合柔性摆动部件。
自动动画参数
自定义函数语法
支持变量 t，范围为 0~1。
范围说明：摇杆函数通常返回 -1 ~ 1，普通滑条函数通常返回 0 ~ 1。
摇杆圆周示例：X(t)=sin(TAU*t)，Y(t)=cos(TAU*t)。
如果想让轨迹更大，可以直接写成 1.6*sin(TAU*t) / 1.6*cos(TAU*t)，再配合范围、响应和回弹调整。
支持运算符 + - * / % < <= > >= == != && || ! ?:
支持常量：PI TAU E
支持函数：sin cos tan asin acos atan atan2 abs min max pow sqrt cbrt log log2 exp floor ceil round sign clamp fract mix lerp step smoothstep saw tri pingpong sin01 cos01 mod repeat saturate invlerp pulse select bezier3 bezier4。
表达式会在导出前校验，确保可以安全写入 3DM INI 自动计算段。

积蓄条配置

绑定滑条/摇杆/开关后，仅统计手柄被鼠标拖拽产生的位移（含模型区域拖拽）；自动动画、物理回弹不计入。
滑条按拖拽距离累计（来回一次记 2），摇杆记两轴位移之和，开关每次点击记 1。达到积蓄槽值时触发下方变量并自动归零重新统计。

嵌套联动（区间映射）

将本组件的值通过区间映射到其他滑块/遥杆组件。例如本组件 0~0.5 映射到目标 0~1。

独立区间触发

无需绑定目标组件，自由设置区间及其进入/离开动作。仅当本组件值进入或离开区间时触发动作。
方向变量按相邻两个方向混合计算；第 0 个方向的角度 = 起始角度 + n × (360 / 方向数量)
前一段到达 1 后保持不变，当前段继续从 0 增长到 1。
启用后，模型侧拖拽交互处于仅命中模式（模式 1）时：按住 Alt 并点击左键（或按 X 键）命中模型指定区域，即绑定本组件手柄——手柄从当前值出发、按鼠标位移相对移动（不会瞬间跳到光标位置）；绑定后移出区域也不会中断，松开左键 / X 键 / Alt 后绑定结束并照常回弹/吸附。面板关闭（Home 收起）时同样生效，模式 0 / 2 不会触发绑定；光标在组件上的原有拖拽不受影响。
“区域变量名”必须与模型侧（TheHerta4 拖拽交互节点）导出的命中区域变量一致——节点保留默认名 ssmtdrag_ui_zone 时会自动追加命名空间后缀，请填写节点上显示的最终变量名（如 $ssmtdrag_ui_zone_xxx），命名空间会自动从该变量名推导并用于匹配模型侧按键状态变量；“命中区域编号”与节点的区域 ID 完全一致，未命中时该变量为 -1。
浏览器内的布局预览无法模拟，导出后在游戏内生效。
